## Creating a working directory and an empty repository  
There are two methods that I can follow:  
The first method is to make a directory, change to that directory, and execute the command **git init** which initiates an empty git repository in the working directory. </br>  
<img width="876" height="534" alt="Screenshot From 2026-11-09 21-19-37" src="https://github.com/user-attachments/assets/b63fb69b-abf5-4060-a898-9cc9b2ed3273" /> </br>  

The second method is to execute the command **git init repository-name**. This command will initiate git version control and also create the working directory with
the **repository-name** - as shown in the image below. </br>

## git status command  
The textbook definition of the **git status** command is - "show the working tree status".  
Using the **nano** text editor, I have created a text file (**code.txt**) inside my working directory (**app1**). I have entered a single line of text in the file.  
I have executed the **git status** command after saving the text file to note down the status. <br>  
<img width="468" height="91" alt="Screenshot From 2026-11-12 18-18-08" src="https://github.com/user-attachments/assets/221afa82-d71f-468d-9466-af728e353e6c" />  
<img width="803" height="260" alt="image" src="https://github.com/user-attachments/assets/249a604f-c3b8-4cb3-bb9c-32eaee9a37fc" />  
At this point, the file **code.txt** is an **Untracked File** because it exists in my **working directory** but I have not asked **git** to manage it.  
So the next step is to add the file using the **git add** command.
