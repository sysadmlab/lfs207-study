# Startup Files:  
The startup files contain the definition for:  
1. Environment variables used by programs and scripts  
2. Aliases for commands and options  
3. Functions used by scripts

Startup files can also be used to determine the default text editor and modify the prompt in the command line.  

The **startup files** are found in the **/etc** directory and in the **home** directory of each individual user. The files in the **/etc** directory are **system-wide** global. However, the settings in the startup files for each individual user take precedence and override the settings in the **system-wide** global files. Which file is used and in what order depends on context.
