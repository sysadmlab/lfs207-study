# Lab 3.2: Command history  

### Assuming that I don't remember the command at all:  

1. Ascertaining a command can be achieved using the command **history**. The **history** command can be combined with the **less** pager command for a page-by-page review of all the commands I have typed - taking into consideration the number of lines the history can hold. </br>
<img width="526" height="546" alt="image" src="https://github.com/user-attachments/assets/eca3f283-eb2c-4e3b-a5a5-215f06f58d56" />  

2. Once I have identified the command, I can execute the particular command by executing **!<the-corresponding-number-of-the-command>** for example **!5**. This will execute the command at position 5 in that list. </br>

### Assuming I can remember a part of the command:  
1. If I remember part of the command, I can search using keywords. Let's say I don't remember **udisks2** but I know the command had the word **disk** in it, I can search using the keyword **disk**.
2. To achieve this, I can execute the command **history**, then press **CTRL+R** and type **disk** at the prompt. This will list the commands that have the keyword **disk** in it - starting with the latest instance going up the list to the earliest instance. </br>

3. Once I have found the command I was searching for, I can hit **Enter** and execute the command.
