# Exercise 6.1: Using chmod  

## Try the following examples:  
**chmod u=r,g=w,o=x afile**  
**chmod u+w,g-w,o+rw afile**  
**chmod ug=rwx,o-rw afile** </br>  

After each step do:  
**ls -l afile** to see how the permissions took, and try some variations. </br>
