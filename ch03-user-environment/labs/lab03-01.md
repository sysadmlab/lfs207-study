## What are the security considerations in altering the path this way?  
The problem with point 4 above is that anyone can sneak in an executable file and make it part of the PATH variable. Bash will read the PATH variable from left to right and the first occurrence of the **ls** program will be executed. This malicious file may contain code and can breach the system and the network.
