# Lab 3.1: Adding the "~/work" directory to your path (PATH)  
1. Create a small file, "**~/work/ls**", which contains just the line: echo HELLO, this is the phony ls program.  
2. Then make the "**ls**" file executable.  
3. Append "**~/work**" to your path (PATH), so it is searched only **after** your usual path is considered. Type **ls** and see which program is run.  
4. Pre-pend "**/work**" to your path, so it is searched **before** your usual path is considered. Once again, type**ls** and see which program is run.
