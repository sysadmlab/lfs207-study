# Lab 7.1. Version Control with git  

## Installing git package  
The Rocky Linux virtual machine used for this demonstration does NOT have **git** installed. Executing the command **which git** reports that
the **git** package is not installed.  
Hence, I installed the **git** package using the command **sudo dnf install git** </br>

## Creating an empty repository  
There are two methods that I can follow to creating an empty repository.  
The first method is to make a directory, change to that directory, and execute the commant **git init** - as shown in the image below. </br>  
<img width="876" height="534" alt="Screenshot From 2026-11-09 21-19-37" src="https://github.com/user-attachments/assets/b63fb69b-abf5-4060-a898-9cc9b2ed3273" /> </br>  

The second method is to execute the command **git init <repository-name>**. This command will initiate git version control and also create a directory with
the **<repository-name>** - as shown in the image below. </br>  
<img width="876" height="534" alt="Screenshot From 2026-11-09 21-20-49" src="https://github.com/user-attachments/assets/bcbbbbdd-c241-4363-9f2f-c2d330caffce" /> </br>  

Irrespective of the methods, the empty repository consists of the hidden directory and sub-directories and files. </br>
