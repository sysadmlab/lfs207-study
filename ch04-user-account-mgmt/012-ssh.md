# Secure Shell (SSH)  
**Secure Shell (SSH)** allows a user to **securely** connect to a remote computer for administration, to transfer files, and to copy data. SSH encrypts the data transmitted between the local and the remote computer, ensuring security and integrity of the communication. </br>  
Needless to say, SSH uses the underlying **Network** for communication. By default, SSH uses **TCP** Port **22**. </br>  
SSH has **Client** and **Server** roles which allows computers to initiate outgoing connections and receive incoming connections respectively. While all the distributions I use have the **Client** package, Rocky Linux and Alma Linux have the SSH **Server** installed and enabled by default, openSUSE has the Server part installed but **Disabled** by default, and Ubuntu Server does **NOT** have the **Server** package installed by default. </br>  
By executing **which ssh** I can check if the **Client** package is available and **which sshd** to check if the **Server** package is available. Also, by executing **systemctl status sshd** I can check whether the SSH Daemon (Service) is active or disabled. </br>

# Saving connection settings in Config file:  
Instead of entering the **user-account@IP-Address** with the **ssh** command, I can save this information in a **Config** file at **~/.ssh/config** on the local computer.  
This method helps me create aliases for the remote computers I am connecting to instead of remembering host names, user accounts, and IP addresses.  
I can provide a custom name for the remote I am connecting to, along with the remote computer's **hostname**, **port** number, and **user account** - as shown in the image below: </br>  
<img width="822" height="671" alt="image" src="https://github.com/user-attachments/assets/9625af47-f33a-4b3c-b4a3-784bb617f93c" />  
In addition to hostname, user-account, and IP address, other SSH settings can be saved in this file such that they are applied while connecting to that specific host. </br>  

## Note: Order for Configuration Settings:
The **command line options** are given first preference, the second preference is given to the Configuration settings in the file **/home/<user>/.ssh/config**, and the third preference to the Configuration settings in the file **/etc/ssh/ssh_config**
